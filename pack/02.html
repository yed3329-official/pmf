MPS → PMF for PSP

Adds the 2048-byte PSMF header to a PSP-ready MPEG program stream. It does not re-encode anything, so it runs fast and offline.

Pick an .mps file.
The MPS must already be PSP-style: H.264 video, ATRAC3+ audio in private stream 1, starting with a pack header. Width and height should match the video.
